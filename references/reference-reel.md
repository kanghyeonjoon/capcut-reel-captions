# 레퍼런스 릴스에서 배운 것

레퍼런스는 소운 계정의 "21살에 1500만원짜리 강의를 결제했습니다" 릴스(약 34만 회)다. 1027 영상(10/27)에 적용하며 정리했다.

## 스킬에 들어간 것

| 레퍼런스 | 스킬에서 |
|---|---|
| 자막을 2~4단어씩 짧게, 약 1~1.5초마다 바꿈 | 줄 나누기 목표 7자, 13자 넘지 않게, 1.5초 넘으면 나눔 |
| 굵은 고딕, 흰 글자 + 검은 테두리 | 고딕-Blk 14, 테두리 0.08, 옅은 그림자 |
| 숫자만 파란색("1500") | 숫자(+년·살·원·개월 등)는 자동으로 파란색 |
| 노을 같은 감성 장면은 얇은 글꼴 | `kind: "calm"`: 제주명조체 15, 테두리 없이 그림자, 화면은 천천히 1.06배까지 다가감 |
| 2~3초마다 장면이 바뀌고, 바뀔 때 살짝 확대됐다가 자리 잡음 | 컷마다 넓게/가깝게(1.0/1.12) 번갈아, 첫 0.18초 6% 크게 시작 |
| 소리가 크고 또렷함(중간 -18dB쯤) | 말소리를 -20dB 쪽으로 최대 +6dB 키움 |
| 끝에 프로필 화면 녹화 + "지켜봐 주세요!!!" | 계정 이름 + 한 줄 소개 글 |

## 아직 자동으로 못 하는 것 (재료가 필요함)

- **장면 바꿔 끼우기(B-roll):** 레퍼런스는 축구장, 사무실, 버스 같은 다른 장면을 계속 바꿔 끼운다.
  - 한 장면만 찍은 영상은 넓게/가깝게로 대신한다.
  - 사용자가 다른 장면 영상을 주면, 말에 맞는 자리에 위쪽 트랙으로 넣는 것을 제안한다.
- **디졸브:** 감성 구간으로 넘어갈 때 디졸브를 쓴다. 같은 장면끼리는 어색해서 넣지 않았다.
- **마지막 프로필 화면 녹화:** 사용자가 화면 녹화를 주면 끝에 붙인다.
- **배경음악:** 캡컷 안에서 사용자가 고르는 편이 낫다. 넣는다면 말소리 아래 -20dB 이하로 깐다.

## 레퍼런스를 새로 분석할 때

`scripts/sheet.swift`로 1초 간격 장면을 한 장에 모아 본다.
- 컴파일: `swiftc -O sheet.swift -o bin/sheet`
- 실행: `CELL_W=180 CELL_H=320 bin/sheet 출력.jpg 8 영상@0 영상@1 ...`

한 장에서 볼 것:
- 자막 길이와 바뀌는 간격
- 글꼴 종류
- 강조색
- 장면이 바뀌는 간격
- 확대 움직임

소리 크기는 `envelope`로 재서 1027과 비교한다.
